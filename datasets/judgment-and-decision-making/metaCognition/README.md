# unpublished metacognitive estimation

True/false state-capital questions with a confidence rating, collected as a course assignment at UC Irvine (IRB 4286). Fifty questions. `truth` and `answer` use `1` = yes/true and `2` = no/false. `confidence` is the rating given with that answer. `correct` is 1 when `answer` matches `truth`.

`participant` IDs are anonymous integers and match `bart`, `gasPrices`, and `fishPrices` for the same person.
