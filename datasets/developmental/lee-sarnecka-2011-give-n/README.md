# Lee & Sarnecka (2011) Give-N

Lee, M. D., & Sarnecka, B. W. (2011). Number-knower levels in young children: Insights from Bayesian modeling. *Cognition*, 120(3), 391–402. [doi:10.1016/j.cognition.2010.11.002](https://doi.org/10.1016/j.cognition.2010.11.002)

Give-N: the child is asked for a number of objects and gives some number. 56 children, 1,104 trials.

## Within-participant tasks

The same 56 children also did fast-cards. **`participant` IDs 1–56 are the same child** in both folders. Join on `participant`.

| Task | Folder |
|------|--------|
| Give-N (this dataset) | [lee-sarnecka-2011-give-n](../lee-sarnecka-2011-give-n/) |
| Fast-cards | [lee-sarnecka-2011-fast-cards](../lee-sarnecka-2011-fast-cards/) |

## Files

- `trials.csv` — `participant`, `question` (how many requested), `answer` (how many given)
