# Lee & Danileiko (2014) probability estimates

Lee, M. D., & Danileiko, I. (2014). Using cognitive models to combine probability estimates. *Judgment and Decision Making*, 9, 259–273.

Two samples of **145 people** and **40 questions** each (5,800 rows per file). `participant` IDs restart at 1 in each file and should not be joined.

## Files

- `generalKnowledge.csv` — percentage facts (truth is a percent)
- `soccer.csv` — probability that a leading soccer team wins

## Columns

- `question`, `questionText`
- `truth` — objective answer
- `estimate` — that person’s report
