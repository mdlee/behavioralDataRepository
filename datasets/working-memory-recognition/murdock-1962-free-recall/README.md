# Murdock (1962) free recall

Murdock, B. B., Jr. (1962). The serial position effect of free recall. *Journal of Experimental Psychology*, 64, 482–488.

Classic list-length × presentation-rate serial-position counts. These are aggregated counts, not individual trial data.

## Files

- `serialPositionCounts.csv` — long form (position ≤ list length only)
- `murdock1962Wide.csv` — original wide matrix used in *Bayesian Cognitive Modeling*

## Columns (`serialPositionCounts.csv`)

- `listLength`
- `presentationRateSec` (the fractional part of the original first column, e.g. 10.2 → length 10, 2 s)
- `serialPosition`
- `recallCount`
