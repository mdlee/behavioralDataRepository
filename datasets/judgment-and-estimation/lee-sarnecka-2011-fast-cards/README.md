# Lee & Sarnecka (2011) fast-cards

Lee, M. D., & Sarnecka, B. W. (2011). Number-knower levels in young children: Insights from Bayesian modeling. *Cognition*, 120(3), 391–402. [doi:10.1016/j.cognition.2010.11.002](https://doi.org/10.1016/j.cognition.2010.11.002)

Fast-cards: the child sees a number of objects briefly and says how many. 56 children, 1,114 trials.

## Within-participant tasks

The same 56 children also did Give-N. **`participant` IDs 1–56 are the same child** in both folders. Join on `participant`.

| Task | Folder |
|------|--------|
| Give-N | [lee-sarnecka-2011-give-n](../lee-sarnecka-2011-give-n/) |
| Fast-cards (this dataset) | [lee-sarnecka-2011-fast-cards](../lee-sarnecka-2011-fast-cards/) |

## Files

- `trials.csv` — `participant`, `question` (how many shown), `answer` (verbal response)
