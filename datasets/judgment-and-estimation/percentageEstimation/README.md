# unpublished percentage estimation

Percentage estimates collected as a course assignment at UC Irvine (IRB 4286). Each row is one question. Estimates are the number entered (percentage points, not proportions).

`participant` IDs are anonymous integers and match `bart`, `gasPrices`, and `fishPrices` for the same person. `quarter` and `session` distinguish repeated sittings.

| Quarter | People | Questions | Notes |
|---------|--------|-----------|-------|
| W2023 | 197 | 44 | No separate research-consent item; finished responses with a complete answer vector (198 sittings) |
| W2024 | 170 | 25 | Research-consent filter (173 sittings) |
| F2025 | 146 | 25 | Two slider-start forms (`form1`, `form2`); research-consent filter (148 sittings) |

## Columns

- `participant`, `quarter`, `session`, `condition`
- `question`, `questionLabel`, `truth`, `estimate`

`condition` is `single` in W2023 and W2024, and `form1` or `form2` in F2025.
