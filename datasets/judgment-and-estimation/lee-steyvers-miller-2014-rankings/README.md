# Lee, Steyvers, & Miller (2014) rankings

Lee, M. D., Steyvers, M., & Miller, B. (2014). A cognitive model for aggregating people’s rankings. *PLoS ONE*, 9(5), e96431.

Each CSV is one ranking domain. `tasks.csv` lists domains and the true order of items. Other files are raw rankings: rows are people, columns are list positions, entries are the true-order index of the item placed there.

See the paper for task names and scoring.
